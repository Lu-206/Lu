# 京途 AI · 沉浸式北京旅行首页

React 19 + TypeScript + Vite + Tailwind CSS + GSAP ScrollTrigger。

```sh
npm ci
npm run dev
```

打开 Vite 输出的本地链接（默认 http://localhost:5173/）。构建：`npm run build`。

## 交互

- 桌面端五幕固定舞台，滚动驱动图片缩放、位移、转场与文字错速移动。
- 鼠标驱动照片与描边文字不同方向的微视差，最大偏移 23px。
- 右侧章节按钮跳转，首屏与固定导航均可打开旅行需求表单。
- 六个景点详情、添加旅行想法、快捷需求、天数与预算选择。
- 移动端分段场景、汉堡导航；减少动态效果偏好下关闭固定滚动动画。
- 弹窗支持 Escape、焦点循环和关闭后返回原触发点。

当前 AI 规划保留为明确标记的前端演示，未连接模型、地图、预订或实时旅游数据接口。

## 第二轮设计优化

新增北京摄影精选与三处交互重设计：

- 介绍区：ThreeUI Topo Field 改造的金色地形线，四类功能可切换；中轴线示意可点选节点。
- 规划区：主题选择联动实景图片和输入内容，增加旅行登机牌与轻量光轨按钮。
- 规划弹窗：摄影侧栏、步骤进度、联动预设、旅行节奏选择与确认摘要；手机端转为单栏。

模板筛选与改造记录：[docs/design-sources.md](docs/design-sources.md)。

验证：生产构建、1440 桌面端、390/768 移动端、四类功能切换、节点选择、主题与输入联动、预设天数/预算同步、确认及返回修改、Escape 关闭、减少动态效果模式。

## 第三轮：日光配色与经典摄影试版

去掉整图压暗与去饱和滤镜；主视觉采用浅色局部渐变及深色文字；体验台保持布局与操作，改为暖白底和淡金地形线。轮换图、体验图、景点封面和规划图均调整。
